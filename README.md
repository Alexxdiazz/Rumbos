Rumbos – Plataforma de exploración y planificación de viajes

Aplicación web para explorar destinos turísticos, descubrir lugares de interés y organizar viajes en un único espacio.

Alcance del sistema: Explorar destinos turísticos, guardar destinos y puntos de interés turístico, crear viajes personalizados, organizar itinerarios por día, registrar presupuestos y gastos.
Base de datos planificada: PostgreSQL a través de Supabase.
Stack Tecnológico:
SvelteKit 
TypeScript
PostgreSQL / Supabase(Base de datos planificada)
integrante: Alexis Díaz

Cómo ejecutar el proyecto

---bash--
npm install
npm run dev
